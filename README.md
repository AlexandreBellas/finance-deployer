# finance-deployer

GitHub Actions workflows that deploy self-hosted finance apps to Hostinger shared hosting.

- `.github/workflows/deploy-finance.yml` deploys Firefly III.
- `.github/workflows/deploy-investments.yml` deploys [AlexandreBellas/investbrain](https://github.com/AlexandreBellas/investbrain). Start it manually. By default it builds that fork's `main` HEAD, resolved to a commit SHA. Pass the `ref` input to build another branch, tag, or SHA from the same fork. It does not use upstream `investbrainapp/investbrain` releases. The archive is uploaded over SSH and does not contain `.env`. The remote step swaps in a fresh tree so files removed upstream (such as `config/sanctum.php`) cannot linger, and the document root is mode 755, including after a rollback. It keeps the server `.env` and `storage/`. If the server has no `.env`, one is written from repo secrets at mode 600. Passport encryption keys are created in `storage/` when they are missing and linked into the existing storage directory, so a rollback keeps them. Public HTTP checks run before the previous tree is deleted: `/login` must return 200, and an unauthenticated `GET /api/dividend` that asks for JSON must return 401. A failed check prints a redacted Laravel log tail and restores that tree.
